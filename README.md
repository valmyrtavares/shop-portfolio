# Shop Portfolio | Minimalist Handmade Goods

A premium, minimalist e-commerce portfolio template designed for high-end handmade brands. This project showcases a luxury aesthetic with focus on craftsmanship and visual storytelling.

## ✨ Features

- **Luxury Hero Section**: High-impact entrance with smooth animations and premium typography.
- **Dynamic Product Grid**: Clean layout showcasing products with hover effects.
- **Detailed Product Modal**: Full-screen quick view for an immersive product experience.
- **About Section**: Dedicated space for brand storytelling and craftsmanship details.
- **Fully Responsive**: Optimized for all device sizes (mobile, tablet, desktop).
- **Sass Modules**: Modular and maintainable styling architecture.

## 🛠️ Tech Stack

- **Framework**: [React](https://reactjs.org/)
- **Build Tool**: [Vite](https://vitejs.dev/)
- **Styling**: [Sass (SCSS)](https://sass-lang.com/)
- **Icons**: SVG & Lucide-like custom paths.
- **Deployment**: Optimized for [Vercel](https://vercel.com/).

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/YOUR_USER/shop-portfolio.git
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

## 📦 Build

To create a production-ready bundle:

```bash
npm run build
```

The output will be in the `dist/` directory.

## 🎨 Design Philosophy

The design follows a "Quiet Luxury" aesthetic:
- **Typography**: Minimalist sans-serif with generous letter spacing.
- **Palette**: Neutral tones (Whites, Off-whites, Grays, and Deep Black).
- **Space**: Extensive use of whitespace to let the products "breathe".
